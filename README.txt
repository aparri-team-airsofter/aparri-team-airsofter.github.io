# Aparri Team Airsofter — website files

## Included
- `index.html` — all website content and sections
- `styles.css` — responsive dark-green tactical styling
- `script.js` — contact links and registration behavior
- `assets/Neon Jungle Airsoft Emblem.png` — original editable vector team emblem
- `assets/design-preview.png` — generated design concept reference (if included)

## Before publishing: edit these details
Open `script.js` in a text editor and replace:
1. `hn6757464@gmail.com` with the team's real email address.
2. `https://www.facebook.com/share/1JGkHgNkRY/?mibextid=qi2Omg` with the team's real Facebook Page URL.
3. Optionally set `GOOGLE_FORM_URL` to a Google Form URL.

The registration form is a starter version. Without a Google Form URL, it opens the visitor's email app; it does not save registrations to a database. For reliable online submissions, create a Google Form and paste its public responder URL into `GOOGLE_FORM_URL`.

## Add your own photos
Create or use three photos and save them in the `assets` folder with these exact names:
- `gallery-1.jpg`
- `gallery-2.jpg`
- `gallery-3.jpg`

Use photos you own or have permission to publish. If you don't have photos yet, the gallery still shows designed placeholder panels.

## Publish free with GitHub Pages
1. Sign in at https://github.com/
2. Create a **public** repository named exactly `YOUR-GITHUB-USERNAME.github.io`.
3. Extract this ZIP file on your computer.
4. Upload the contents of the extracted folder (not the outer folder) into the repository's root. Keep the `assets` folder.
5. Commit the files to the `main` branch.
6. In the repository, open **Settings → Pages**.
7. Under **Build and deployment**, choose **Deploy from a branch**.
8. Select branch `main` and folder `/ (root)`, then click **Save**.
9. Wait for the Pages deployment to finish. Your site address is:
   `https://aparri-team-airsofter.github.io/`

## Important
- GitHub Pages hosts static websites. This package does not include a private member database, admin login, or server-side registration storage.
- Do not publish private phone numbers, home addresses, or sensitive member information.
- Keep airsoft activity safe, lawful, and compliant with venue rules and applicable local requirements.
